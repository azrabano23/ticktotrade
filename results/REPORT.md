## Assumptions and caveats

- Simulation only (Icarus Verilog). Clock rates are assumed, not achieved: no place & route, no static timing analysis.
- Latency is measured from the first byte of the MoldUDP64 payload on the RTL input bus. A real NIC path adds MAC/PCS (and Ethernet/IP/UDP header) latency on ingress and a TCP/SoupBinTCP stack + MAC/PCS on egress, which are not modelled.
- Market data is synthetic. The strategy is a toy.
